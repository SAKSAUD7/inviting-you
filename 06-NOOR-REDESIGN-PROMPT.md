# NOOR V2 — FLAGSHIP DESIGN PROMPT

## Name

NOOR

## Tagline

A Moonlit Nikah

## Positioning

A cinematic Islamic wedding invitation inspired by moonlit courtyards, architectural silhouettes, quiet light and intimate storytelling.

It must NOT feel like a generic green/gold Islamic card.

---

# DESIGN DNA

Mood:

quiet
mysterious
intimate
luxurious
editorial
spiritual
modern

Palette:

midnight
warm ivory
muted antique gold
deep emerald as optional accent

Avoid:

bright yellow gold
heavy ornament
generic mosque stock art
random Islamic icons
over-decoration

---

# OPENING STORY

Scene 01
Near-black.

Scene 02
One star.

Scene 03
More stars slowly appear.

Scene 04
Crescent becomes visible.

Scene 05
Moonlight spreads.

Scene 06
Architectural arch silhouette appears.

Scene 07
Subtle geometry emerges.

Scene 08
Initials appear.

Scene 09
Names reveal.

Scene 10
"A Moonlit Nikah"

Scene 11
Invitation transitions into the main site.

The opening should feel like a short film.

---

# VISUAL DEPTH

Layer:

sky
stars
moon
distant architecture
foreground architecture
atmosphere
typography

Use subtle parallax.

Do not make everything move.

---

# HERO

Hero should be visually dominant.

Possible composition:

large couple names
small Hijri/Gregorian date
architectural frame
moon
subtle animated atmosphere

Optional couple photo should be treated as an editorial portrait, not a generic card image.

---

# INVITATION

Present the Islamic verse/invitation with breathing room.

If the client supplies a verse, use it.

If not, use a neutral editable invitation message.

Do not hardcode religious wording as permanent content.

---

# COUPLE

Do not use two generic cards.

Use an editorial composition.

Option:

Bride portrait
+
Groom portrait

with names separated by a vertical gold line or architectural motif.

Alternative:

One large couple image with layered typography.

Allow the template to select the strongest layout based on available data.

---

# STORY

Section title:

TWO STORIES
ONE BEGINNING

Show:

how they met
proposal
journey
family message

Only show fields that exist.

No empty blocks.

---

# EVENTS

Ceremonial presentation.

Each event gets:

name
date
time
venue
description
map

Do not use dashboard cards.

Use architectural framing, editorial typography and subtle reveal.

---

# GALLERY

Default layout:

editorial asymmetric gallery.

Features:

- large hero image
- supporting images
- masked reveals
- slow zoom
- parallax
- fullscreen lightbox

Do not use a generic 3-column grid.

---

# VENUE

Transition:

EVENT
→
VENUE
→
LOCATION

Show:

venue name
address
map
directions

Keep map visually subordinate.

---

# RSVP

Headline:

WE WOULD LOVE
TO SEE YOU THERE

Buttons:

YES, I'LL BE THERE

SORRY, I CAN'T MAKE IT

Confirmation should animate elegantly.

If guest management exists, support:

name
events
seats
dietary
message

---

# SIGNATURE MOMENTS

1. Moon Reveal
2. Architectural Reveal
3. Constellation Couple Reveal
4. Lantern Event Reveal
5. Moonset Closing

These five moments define Noor.

---

# CLOSING

Return to the moon.

Reduce motion.

Couple names.

Short closing message.

Fade to darkness.

Ensure contrast.

Use accessible controls.

Respect keyboard interaction on desktop.

GSAP
SVG
optimized media

Use:

responsive images
poster frames
code splitting

---

# FINAL FEELING

The guest should think:

"That was beautiful."

Not:

"That had lots of animations."
