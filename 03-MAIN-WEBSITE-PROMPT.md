# MAIN WEBSITE — MASTER IMPLEMENTATION PROMPT

Build the main Inviting You website as a premium digital invitation showroom.

## POSITIONING

Do not present it as a generic invitation generator.

Position it as:

**Premium Digital Wedding Experiences**

Core feeling:

luxury
cinematic
editorial
cultural
modern
trustworthy

---

# HOMEPAGE

## Hero

Use an immersive visual hero.

Headline direction:

"Invitations worth opening."

Subheadline:

"Beautiful digital wedding experiences, designed to be remembered."

Primary CTA:

Explore the Collection

Secondary CTA:

Watch a Live Experience

The hero should include a living invitation preview, not a static screenshot.

- live animated preview
